Nạp firmware cho robot

  1. Dùng Chrome hoặc Edge trên máy tính (Web Serial không chạy trên Firefox / Safari / điện thoại).
  2. Cắm robot vào máy bằng cáp USB có truyền dữ liệu.
  3. Bấm nút bên dưới, chọn cổng COM của robot rồi chờ nạp xong.
Trình duyệt này không hỗ trợ Web Serial. Hãy dùng Chrome hoặc Edge. Cần mở trang qua HTTPS (hoặc localhost).

Trước khi dùng, đặt file merged-binary.bin (lấy từ bản release, hoặc tạo bằng idf.py merge-bin) cùng thư mục với trang này. Chạy thử trên máy: python -m http.server 8000 rồi mở http://localhost:8000.
